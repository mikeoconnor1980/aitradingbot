### Task 3.2: Create health response model and health API service {#task-32-create-health-response-model-and-health-api-service}

Create a TypeScript interface matching the backend `HealthDto` and a service with polling and manual refresh support.

- **Complexity**: Medium
- **Risk Factors**: Polling must use `interval` with `switchMap` + `takeUntilDestroyed` to avoid memory leaks; manual refresh must coexist with polling; error inside `switchMap` must not kill the polling stream
- **Files**:
  - `frontend/trading-ui/src/app/core/models/health-response.model.ts` — Response interface
  - `frontend/trading-ui/src/app/core/services/health.service.ts` — Health API service
- **Success**:
  - Interface matches the backend DTO exactly
  - Service emits health status every 10 seconds
  - Service supports `refresh()` for immediate check
  - Errors inside polling do not terminate the stream
- **Dependencies**: Task 3.1

#### Implementation Details

```typescript
// frontend/trading-ui/src/app/core/models/health-response.model.ts — new file
export interface HealthResponse {
  status: "connected" | "disconnected";
  walletAddress: string;
  network: string;
  timestamp: string;
  error: string | null;
}
```

```typescript
// frontend/trading-ui/src/app/core/services/health.service.ts — new file
import { Injectable, DestroyRef, inject } from "@angular/core";
import { HttpClient } from "@angular/common/http";
import { BehaviorSubject, Observable, Subject, merge, timer, of } from "rxjs";
import { switchMap, catchError, shareReplay } from "rxjs/operators";
import { takeUntilDestroyed } from "@angular/core/rxjs-interop";
import { HealthResponse } from "../models/health-response.model";

@Injectable({ providedIn: "root" })
export class HealthService {
  private readonly _http = inject(HttpClient);
  private readonly _destroyRef = inject(DestroyRef);
  private readonly _refresh$ = new Subject<void>();
  private readonly _healthUrl = "/api/health";

  private readonly _health$ = new BehaviorSubject<HealthResponse | null>(null);

  public readonly health$: Observable<HealthResponse | null> = this._health$.asObservable();

  constructor() {
    merge(
      timer(0, 10_000),
      this._refresh$
    ).pipe(
      switchMap(() =>
        this._http.get<HealthResponse>(this._healthUrl).pipe(
          catchError(() => of<HealthResponse>({
            status: "disconnected",
            walletAddress: "",
            network: "",
            timestamp: new Date().toISOString(),
            error: "Failed to reach backend API"
          }))
        )
      ),
      takeUntilDestroyed(this._destroyRef)
    ).subscribe({
      next: (response) => this._health$.next(response)
    });
  }

  public refresh(): void {
    this._refresh$.next();
  }
}
```

> **Notes**:
> - `timer(0, 10_000)` emits immediately then every 10 seconds
> - `switchMap` cancels in-flight requests when a new trigger fires
> - `catchError` inside `switchMap` prevents errors from killing the timer stream
> - `_health$` is a `BehaviorSubject` — late subscribers get the last known value
> - `$` suffix on infinite observables per knowledge docs convention

- **Complexity**: Medium

  - Refresh button calls `HealthService.refresh()`
  - Handles loading state before first response
- **Dependencies**: Task 3.2

#### Implementation Details

```typescript
// frontend/trading-ui/src/app/features/connection/status-card.component.ts — new file
import { Component, inject } from "@angular/core";
import { CommonModule } from "@angular/common";
import { HealthService } from "../../core/services/health.service";

@Component({
  selector: "app-status-card",
  standalone: true,
  imports: [CommonModule],
  templateUrl: "./status-card.component.html",
  styleUrls: ["./status-card.component.scss"]
})
export class StatusCardComponent {
  private readonly _healthService = inject(HealthService);

  public readonly health$ = this._healthService.health$;

  public onRefresh(): void {
    this._healthService.refresh();
  }
}
```
