# Backtest Price Chart Visualization

**PBI ID:** Draft
**Status:** Draft
**Iteration:** Backlog
**Created:** 2026-03-28T20:32:11Z

## User Story

As a trader, I want to use historical backtest candle data to populate the price chart, so that I can visually see how the grid strategy would have performed on real historical data.

## Problem Statement

After running a backtest, traders can see equity curves and trade logs, but lack a visual price chart showing candle data overlaid with grid levels and trade entry/exit markers. This makes it hard to intuitively understand how the strategy interacted with price action.
